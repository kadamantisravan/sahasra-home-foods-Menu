ADMIN FEATURES
- Add items without touching code
- Edit items
- Delete items
- Create categories
- Delete unused categories
- Add an image URL per item
- Search/filter items
- Download a JSON backup
- Restore a backup
- Reset to the original menu
- Change the admin PIN

DEFAULT ADMIN PIN: 1234

IMPORTANT FOR LIVE USE
This admin panel stores changes in the browser's localStorage. It is designed as a simple no-code starter/admin interface. If the website is hosted publicly and the owner needs changes made on one device to instantly appear for every customer and every device, the website should be connected to a shared database such as Supabase or Firebase. The UI is already structured so this can be added as the next step.
